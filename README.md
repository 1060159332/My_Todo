# Glass Todo (桌面悬浮清单)

电脑桌面待办事项软件（仅支持 Windows）。
界面弄成了半透明的毛玻璃风格，支持置顶和穿透，挂在桌面上当便签用很方便。

## ✨ 主要功能
1.  **极简界面**：可以切换成“极简模式”，只显示一条任务，不占地方。
2.  **桌面挂件化**：支持窗口置顶，甚至可以“锁定”窗口（鼠标穿透），就像壁纸的一部分。
3.  **任务管理**：支持设置优先级、截止日期，还有重复任务（每天/每周等）。
4.  **自动分类**：未来的重复计划会自动折叠，完成的任务也会自动收纳。

##  📖  使用说明

### 1. 基础操作
*   **添加任务**：在最下方的输入框打字，按回车或点击 `+` 号。
*   **删除任务**：点击任务右边的 `✕` 号。
*   **完成任务**：点击任务左边的圆圈。如果是重复任务，它会自动生成下一次的任务。

### 2. 设置任务属性
*   `⚑` **小旗子**：切换优先级（绿=低，黄=中，红=高）。
*   `🔁` **循环图标**：设置重复任务。
*   `⏰` **闹钟图标**：设置截止时间。

### 3. 窗口控制（标题栏按钮）
*   `📌` **置顶**：点一下变绿，窗口会一直显示在最前面，再次点击解除置顶。
*   `🔓` **锁定/解锁**：**注意！这个按钮需要长按 2秒才能生效**（为了防止误触）。
    *   **锁定后**：窗口不再交互，鼠标点上去会穿透（点到后面的桌面），方便你把它挂在屏幕上不影响操作。
    *   **解锁时**：**注意！**只能去右下角系统托盘右键解锁。
*   `⛶` **切换模式**：在“完整列表”和“极简单行模式”之间切换。
*   `⚙` **设置**：调节窗口透明度和颜色，以及选择窗口退出是缩小到托盘还是直接退出程序。

### 4. 其它
*   **系统托盘**：软件关闭或最小化后会在右下角托盘区有个小图标，右键可以退出或解锁窗口。

## ⚠️ 注意事项
 **关于数据**：第一次运行后，文件夹里会生成一个 `todo_v20.db` (或类似名字) 的文件，**那个是存数据用的，千万别删**，删了任务就没了。
